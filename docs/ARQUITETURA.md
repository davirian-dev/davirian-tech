# Davi Rian Tech (`davirian-tech`) — Arquitetura

> Documento em Markdown (compatível com Obsidian e agentes de IA).

## 1. Visão Geral
- **Nome:** Portfólio Davi Rian Tech (`https://davirian-tech.vercel.app`)
- **Foco:** Portfólio corporativo para criação de sites, bots de WhatsApp/Telegram e automações de vendas com Pix.
- **Stack:** HTML5, Tailwind CSS, JavaScript inline/estático, Vercel (`vercel.json`).

## 2. Estrutura do Projeto
- `index.html`: Landing page principal com seções de serviços, portfólio e contato.
- `privacidade.html`, `termos.html`, `robots.txt`, `sitemap.xml`, `vercel.json`.
- `assets/` e `assets/videos/`: Fotos profissionais em `.webp`/`.jpg` e vídeos teaser `.mp4`.

## 3. Regras para IA
1. **Preservar SEO & Meta Tags:** Manter Open Graph, `sitemap.xml` e `robots.txt` atualizados ao alterar títulos, descrições ou rotas.
2. **Links Oficiais:** Usar sempre as URLs oficiais dos projetos do ecossistema ao atualizar cards do portfólio.
